# Prefab Web

[Prefab](../prefab-api)의 프론트엔드. 회로도와 펌웨어를 올리면 검사 결과를 보여줍니다.

판정 로직은 전부 [`prefab-api`](../prefab-api)에 있습니다. 이 저장소는 화면만 담당합니다.

---

## 화면

| 라우트 | 역할 |
|---|---|
| `/` | 업로드 — 넷리스트(필수) · BOM(선택) · 펌웨어(선택) |
| `/c/{id}` | 처리 중 — 파이프라인 7단계 진행 |
| `/r/{id}` | 리포트 — 요약 · 발견 목록 · 넷리스트 부록 |

결과는 **URL만으로 열립니다.** 로그인이 없습니다.

---

## 디자인

**제도 도면 검토서** 컨셉입니다. 사수가 빨간 펜으로 봐준 도면.

시그니처는 발견 카드 가운데를 지나는 **빨간 이음매**입니다.
왼쪽은 회로도가 말하는 것, 오른쪽은 코드가 말하는 것. 어긋남이 그 사이에서 발생합니다.
제품의 논지가 곧 레이아웃입니다.

```
--vellum  #E6E9E4   제도 용지
--ink     #171C26   제도 잉크
--redpen  #C0322A   교정 빨간펜 · 이음매
--amber   #A9700F   확인 필요
--verify  #2C6248   해제됨
```

폰트는 IBM Plex 계열(Sans KR / Condensed / Mono). 모서리 반경 0.
리포트 구조는 Chrome Lighthouse를 참고했습니다 — 요약 → 심각도별 발견 → 근거 → 수정 방법,
그리고 "해제됨" 항목은 접어서 하단에 둡니다.

## 빠른 시작

```bash
pnpm install
cp .env.example .env        # VITE_API_BASE 설정
pnpm dev                    # http://localhost:5173
```

`VITE_API_BASE`를 비워두면 `src/mocks/check.json`으로 동작합니다.
백엔드 없이 화면 작업을 할 수 있습니다.

```bash
pnpm build && pnpm preview
```

## 원칙

**숫자를 지어내지 않습니다.** API가 0을 주면 0으로 표시하고, `null`은 `—`로 둡니다.
미구현 기능은 "미구현"이라고 씁니다.

**못 한 일을 숨기지 않습니다.** BOM이 없어서 데이터시트 단계를 건너뛰었으면
그 사실과 사유를 화면에 그대로 보여줍니다. 흐리게 처리하거나 감추지 않습니다.
무엇을 못 했는지 보이는 것이 이 제품의 신뢰입니다.
