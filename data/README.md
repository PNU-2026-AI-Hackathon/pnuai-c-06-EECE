# data/ — 실제 매장 데이터 넣는 곳

## 가장 쉬운 방법: 화면에서 올리기

`npm run dev` 후 **설정 → 매출 파일 올리기**에 CSV를 끌어다 놓으면 됩니다.
홈·주간 리포트·수요 예측이 전부 그 파일로 다시 계산됩니다.
"예시 데이터로 되돌리기"를 누르면 기본 시연 매장으로 돌아갑니다.

⚠ 올린 데이터는 **서버 메모리에만** 있습니다. `npm run dev`를 재시작하면 사라집니다.
백엔드와 DB가 붙기 전까지의 임시 방식입니다.

## 기본 시연 데이터를 바꾸려면

1. 매출 파일을 이 폴더에 넣는다 (`.csv`)
2. `store.json`에 매장 정보와 파일 경로를 적는다
3. 실행

```bash
npm run build:data
npm run dev
```

파일 경로만 바꿔 한 번 돌려보려면:

```bash
npm run build:data -- --file=data/우리가게_2025.csv
npm run build:data -- --store=data/다른매장.json
```

## 매출 파일에 필요한 것

**필수는 두 개뿐입니다.**

| 항목 | 컬럼 이름 (아무거나 하나) |
|---|---|
| 날짜 | `date` `날짜` `영업일` `거래일` `판매일` `일자` |
| 금액 | `총매출` `매출` `결제금액` `판매금액` `금액` `amount` `total` |

**있으면 분석이 늘어나는 것**

| 항목 | 컬럼 이름 | 켜지는 기능 |
|---|---|---|
| 메뉴명 | `메뉴명` `상품명` `품목` `menu` | 메뉴별 분석 |
| 결제 시각 | `결제시각` `시간` `time` (날짜 컬럼에 붙어 있어도 됨) | 시간대별 매출 |
| 메뉴 + 시각 | 둘 다 | **판매 조기 종료 탐지** |
| 수량 | `수량` `판매수량` `quantity` | 정확한 판매량 (없으면 1건=1개) |

날짜는 `2025-10-19` `2025.10.19` `2025/10/19` 다 읽습니다.
금액은 `1,320,000` `1320000원` 다 읽습니다.

**요일·주 시작일·총수량은 넣지 마세요.** 날짜와 수량에서 계산합니다.

## 파일 모양 두 가지 — 자동으로 알아봅니다

**A. 일별 집계** (하루 한 줄)

```
날짜,총매출,소주_판매수량,맥주_판매수량
2025-10-19,1320000,42,31
```

**B. 결제 내역** (결제 한 건이 한 줄) — 실제 POS는 대개 이쪽

```
날짜,결제시각,메뉴명,수량,결제금액
2025-10-19,19:12,소주,1,5000
```

**B가 훨씬 낫습니다.** 시간대별 매출과 조기 종료 탐지는 B에서만 나옵니다.

시험용 B형 파일은 `npm run make:sample`로 만들 수 있습니다. **결제 시각이 지어낸 값인 샘플**이니 시연이나 분석에는 쓰지 마세요.

## 학사일정은 매출 파일에 넣지 않습니다

`academic-calendar.json`에 따로 있습니다. POS는 학사일정을 모르고, 그건 매장이 아니라 우리가 가진 정보이기 때문입니다.

날짜만 보고 자동으로 붙습니다. 시험이 끝난 **다음 주 월~금**은 "시험 종료 직후"로 자동 분류됩니다 — 캘린더에 적지 않아도 됩니다.

빌드할 때 `⚠ 학사일정이 없는 날짜 N일`이 뜨면 그 기간의 학기가 캘린더에 없다는 뜻입니다.

### 아직 확정 안 된 일정

`2026-2` 학기는 `"confirmed": false`입니다. **부산대 공식 학사일정으로 교체해야 합니다.**

## 기준 시점

`store.json`의 `"today"`는 "이 날짜까지만 알고 있다고 치고 계산해라"입니다.

- 시연: 특정 날짜로 고정 (`"2025-10-19"`)
- 실제 운영: `null` — 파일의 마지막 날짜를 씁니다

예측 대상 주는 매출 기록이 없어도 됩니다. 날짜와 학사일정만으로 만들어 예측합니다.
